# Frontend e UX

Use React, TypeScript, Vite, Tailwind CSS e Recharts, respeitando a versão instalada. Dados devem vir de contratos tipados da API. Diferencie carregamento, vazio, erro e sucesso; mostre atualização e mantenha filtros coerentes entre cards, gráficos e tabelas.

Escolha visuais pela pergunta: linha para evolução, barras ordenadas para ranking, distribuição para valores, scatter para relações e heatmap/matriz para padrões multidimensionais. Diversifique sem decoração arbitrária e sem repetir barras em todo o painel. Distinga histórico, horizonte previsto e intervalo apenas quando calculado; não desenhe confiança fictícia.

Exiba moeda, unidade, período e denominador com formatação pt-BR. Diferencie nulo de zero; confirme que filtros reproduzem totais da API e comparações usam períodos equivalentes. Permita detalhar agregados respeitando autorização dos registros.

Garanta responsividade, contraste, foco, rótulos acessíveis e alternativa tabular. Não dependa apenas de cor. Trate cancelamento de requisições e respostas atrasadas; limite pontos e pagine tabelas. Verifique desktop/tela estreita quando a tarefa incluir UI, além de tipos e build. Informe se inspeção visual não puder ocorrer.
